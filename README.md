# Generative Neural Networks for Data Imputation in Longitudinal Epidemiological Studies

This repository accompanies the paper  
**“Generative Neural Networks for Data Imputation in Longitudinal Epidemiological Studies”**  
published in *[IEEE Journal of Biomedical and Health Informatics](https://www.embs.org/jbhi/)*.

It provides the data loading and preprocessing pipeline used in the study, including all scripts required to reproduce the EPI-MNIST dataset as well as the model architecture modules.
Hyperparameter configurations, random seed settings, and experiment metadata are provided in the accompanying configuration files.

Please note that no source data are included in this repository. 
For details regarding data availability, please refer to the manuscript.
